# ADR-0001: Adopt Apache License 2.0

- Status: Accepted
- Date: 2026-07-28

## Context

The Self Healing API and Agent OS project is a specification-first initiative intended to foster an open ecosystem of interoperable APIs, agents, runtimes, and tooling.

The project seeks broad community and commercial adoption while protecting contributors through an explicit patent grant. The project should remain accessible to individual developers, enterprises, and vendors implementing the published specifications.

## Decision

The project will be licensed under the Apache License, Version 2.0.

The canonical license text is maintained in the repository's `LICENSE` file.

## Rationale

Apache License 2.0 was selected because it:

- Is a permissive, widely recognized open source license.
- Includes an explicit patent grant and patent retaliation provisions.
- Encourages both open source and commercial adoption.
- Is commonly accepted within enterprise software environments.
- Aligns with the project's long-term goal of creating an open standards ecosystem.

## Consequences

### Positive

- Low barrier to adoption.
- Commercial implementations are permitted.
- Contributors receive patent protections defined by the license.
- Enterprises can adopt the specifications with minimal licensing friction.

### Trade-offs

- Organizations may create proprietary implementations.
- The license does not require derivative works to remain open source.

These trade-offs are acceptable because the project's primary objective is broad adoption of the specifications rather than restricting implementation models.
